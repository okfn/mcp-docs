# Um glossário de domínio

Os dados de energia estão cheios de termos que não significam nada para
quem não é especialista. Para ajudar, pegamos muitas das definições
oficiais do BEN e as disponibilizamos para qualquer pessoa consultar.
Para quem não é especialista de domínio, isso se mostrou essencial.

Fomos um passo além: injetamos essas definições no **contexto das
ferramentas**, para que a própria IA sempre as tenha em mente ao compor
cada resposta, não apenas o usuário.

## O esforço, e por que vale a pena

Dá algum trabalho decidir quais termos se aplicam a qual ferramenta e
quais não. Esse mapeamento é manual e um pouco tedioso. Mas a
recompensa, respostas mais claras e menos mal-entendidos para os não
especialistas, faz o esforço valer a pena.

Se você está construindo um plugin para um domínio especializado,
reserve tempo para um glossário. Não é decoração; ele melhora as
respostas de forma mensurável.
