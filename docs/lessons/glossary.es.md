# Un glosario de dominio

Los datos de energía están llenos de términos que no significan nada
para un no experto. Para ayudar, tomamos muchas de las definiciones
oficiales del BEN y las pusimos a disposición de cualquiera que quiera
consultarlas. Para las personas que no son expertas de dominio, esto
resultó ser esencial.

Fuimos un paso más allá: inyectamos estas definiciones en el **contexto
de las herramientas**, de modo que la propia IA siempre las tenga
presentes al componer cada respuesta, no solo el usuario.

## El esfuerzo, y por qué vale la pena

Lleva algo de trabajo decidir qué términos aplican a qué herramienta y
cuáles no. Ese mapeo es manual y un poco tedioso. Pero la recompensa,
respuestas más claras y menos malentendidos para los no expertos, hace
que el esfuerzo valga la pena.

Si estás construyendo un plugin para un dominio especializado,
presupuesta tiempo para un glosario. No es decoración; mejora las
respuestas de forma medible.
