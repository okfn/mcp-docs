# O projeto

Este capítulo explica o projeto para todo mundo, sem código: o que
construímos, por quê, e o que pensamos sobre IA aplicada a dados
públicos.

- [A ideia](idea.md): o problema que estamos resolvendo e os princípios
  por trás do design.
- [O desafio](challenges.md): por que não dá para confiar apenas nos
  LLMs com dados públicos.
- [Um modelo aberto para dados públicos](open-model.md): os dois
  objetivos, os três eixos e para onde isso vai.
- [Lições dos pilotos](../lessons/index.md): o que dois pilotos com
  governos nos ensinaram, em campo, com usuários reais.

Procurando o lado técnico, a arquitetura, os repositórios, como
executar ou estender a plataforma? Isso está no [guia do
desenvolvedor](../dev/architecture.md).
